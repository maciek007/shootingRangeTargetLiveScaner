# Shooting Range Target Live Scaner
Aplikacja mobilna do skanowania tarczy strzelniczej na żywo z jednego telefonu i wyświetlanie wyników na drugim

# Technologia
Kotlin +  Native C++ do implementacji biblioteki OpenCV

# Funkcjonalności
## Wymagane
- [ ] Znajdowanie tarczy ze zdjęcia
- [ ] Skanowanie w poszukiwaniu nowych trafień
- [ ] Odbieranie komunikatów o trafieniach przez 2. telefon
  - [ ] Wibrowanie w przypadku trafienia
- [ ] Implementacja 1 ze sposobów komunikacji (Bluetooth / sieć lokalna)
- [ ] Zbudowanie aplikacji na Androida

## Opcjonalne

- [ ] Tabela wyników
- [ ] Komunikacja odbiorca - serwer - telefon ze skanującą kamerą
